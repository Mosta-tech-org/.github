# Engineering Principles

MosTa‑TecH engineering follows several core principles.

### Security by design

Authentication, authorization and data isolation are designed into the platform rather than added later.

### Least privilege

Users, services and applications receive only the permissions required for their responsibilities.

### Human approval for high-impact actions

Clinical, prescription, payment-verification and other sensitive decisions require authorized human review.

### Auditable operations

Sensitive actions should generate structured audit records.

### Data isolation

Customer, organization and branch data must remain isolated according to authorization rules.

### Server-authoritative operations

Prices, inventory, permissions and sensitive workflow decisions are calculated and validated on trusted servers or databases.

### Reproducible releases

Production releases should be versioned, reviewed, tested and reversible where technically appropriate.

# Security

Security vulnerabilities should **not** be reported through public GitHub Issues.

Use the private security reporting mechanism provided by the relevant repository.

Never publish:

- passwords;
- API keys;
- access tokens;
- customer information;
- prescription documents;
- payment evidence;
- private business data.
